# NORA_Android_Ejemplo

Proyecto Android/Kotlin generado por NORA desde la plantilla NexusPoc validada.

- Curso: Desarrollo de aplicaciones móviles
- Sección: 002
- Modalidad: EXAMPLE
- NORA Nexus: http://192.168.111.185:8081
- Gradle: 8.13
- Android Gradle Plugin: 8.13.2
- Kotlin: 2.0.21

## Alumno
1. Descomprime el ZIP.
2. Abre esta carpeta en Android Studio.
3. Ejecuta Sync Project with Gradle Files.
4. Espera que finalice la sincronización.
5. Ejecuta la aplicación.

No modifiques `settings.gradle.kts` ni `gradle/wrapper/gradle-wrapper.properties` durante la clase.
